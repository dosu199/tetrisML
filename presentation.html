    2 How it learned

    The method is deep Q-learning, following the open-source project Tetris-deep-Q-learning-pytorch, rewritten in plain JavaScript. Five ideas carry the whole thing.

    1. It sees 4 numbers, not the picture

      For each possible move, the board that move would leave is reduced to four numbers:

      • Lines: rows cleared by this move.
      • Holes: empty cells with a block somewhere above them. ●
      • Bumpiness: how jagged the surface is. It adds up the height jumps between neighbouring columns.
      • Height: all column heights added together.

      The network (4 → 64 → 64 → 1 neurons) turns those 4 numbers into one score. It never learned what a hole is. It only learned that boards with a high "holes" number tend to end badly.

    2. Its only teacher is the score

      Every piece placed earns a reward: 1 + 10 × lines². Just staying alive earns 1, and clearing lines earns much more. Clearing four at once (a "tetris") is worth 16 times a single. Losing simply means no more rewards. That's the entire instruction it gets.

    3. One rule: a board is worth what it pays now plus what comes next

      The network guesses how many points a board will still earn. After each move, the guess is checked against what actually happened: the reward it just got, plus its own guess for the new board (slightly discounted, × 0.99). The gap between the two is the error it trains on. Repeat that over thousands of training steps and real rewards flow backwards to the moves that earned them. This is the Bellman equation.

    4. First it plays randomly, then it trusts itself

      At the start the network knows nothing, so it plays random moves to find out what happens. This is called exploration. Over 2,000 games the share of random moves falls from 100% to 0.1%, and it relies more and more on what it learned.     5. Training is bumpy, so keep the best version

      This is the real training run of the network you're watching (3,000 games, about 4 minutes). It learned slowly while exploring, then took off. But it didn't improve steadily: a network that survived 1,000 pieces could fall to 83 one hundred games later. So every 100 games it plays a short test with no random moves, and only a new best result is saved (). The saved network is from game 2,800.

    3 How good is it?

    The network against a classic search bot with hand-tuned weights. Each line is 50 games the network never saw in training, and every player gets exactly the same pieces. Network + lookahead is the same network, also trying every placement of the next piece.

    Where it's still behind: with fully random pieces and no preview, the bot loses 9 games and the network 12. With the preview and lookahead, the network beats the bot in the hardest mode.
