Watch it learn

The network trained for about 4 minutes, playing 3,000 games. We saved a copy of it at six moments along the way. Below, all six copies play at the same time, with exactly the same pieces, so the only difference between the boards is how much the network had learned.

How to read this page

  • Each board is the same network at a different age. The first one has never trained; the last ones are fully trained.
  • When a board fills up to the top, that game is lost. The board shows how long it lasted, then starts a new game with the next set of pieces.
  • Watch the "avg pieces / game" number. It's the simplest measure of skill: the longer it survives, the better it plays.

↗ Measured, not just watched

The boards above are fun, but a few games can be lucky or unlucky. These are the same six networks, each tested on the same 50 games (normal pieces, no preview, games stopped at 2,000 pieces).

Why so slow at first?

For the first 2,000 games the network was exploring: many of its training moves were random on purpose, so it could discover what happens. A network learns only from what it has seen, and a random player rarely clears a line, so for a long time there was little to learn from.

Why the big jump at the end?

Once it stopped exploring, it played its own best moves. Those games lasted longer and cleared more lines, which gave it better examples to learn from. Better play gave better lessons, which gave better play. Between game 2,200 and 2,800 it went from about 380 pieces per game to never losing.

Why did it get worse at 2,900?

Deep Q-learning chases a moving target: the network learns from its own guesses, and when they shift, a good network can be knocked over. One hundred games later it was down to about 90 pieces. That's why training tests the network every 100 games and keeps only the best one, and why the game uses the copy from game 2,800.

The six copies are in models/snapshots/, made by node scripts/train-dqn.js --snapshots 0,1000,1700,2200,2800,2900. Training is repeatable, so the copy from game 2,800 is exactly the network in models/dqn-model.json.
